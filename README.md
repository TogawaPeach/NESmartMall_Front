# NESmartMall

经纬智选商城前端，使用 Vue 3、TypeScript、Element Plus 与 Axios。

首页已实现分类、搜索、响应式商品卡片及加载/空列表/失败状态。后端尚未开发，当前显示服务未就绪的失败提示，不包含演示商品。

商品接口地址通过 `.env.example` 中的环境变量配置；参数、分类标识、响应字段及价格单位集中在 `src/api/productContract.ts`。对接步骤与待确认事项见 [商品接口契约](docs/product-api-contract.md)。

首页组件位于 `src/components/storefront/`，页面位于 `src/views/HomeView.vue`，查询状态位于 `src/composables/useHomeProducts.ts`。订单、购物车、用户入口及查看全部在对应路由未实现时禁用。

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.
