# 商家商品管理前端验证

日期：2026-10-20

- 有效会话中 `user.role === 0` 登录或首次恢复时进入 `/merchant/products`；普通用户保持原有登录行为。
- 匿名或普通用户直接访问商家页返回商城；退出、会话过期及跨标签切换身份时离开商家页。页面懒加载完成前再次检查身份，覆盖加载期间退出的情况。
- 商家页支持新增、编辑商品名称、型号、分类、售价、库存和说明；新增商品默认下架，可上架或下架。
- 商品数据来自组件内存中的独立示例，不读取或调用商家接口，不修改商城商品。离开页面或刷新后重置。
- 支持搜索名称、型号及编号、按上架状态筛选、分页；校验价格小数位、正价格、非负整数库存等；库存为零时不可上架，在售商品库存不可直接改为零。
- 商家可通过“查看商城”进入前台，再从账号菜单的“商家工作台”返回。

## 验证结果

- `npm test`：318/318 通过，包含 7 项商家导航与本地商品操作测试。
- `npm run build`：生产构建及 TypeScript 检查通过。
- `git diff --check`：通过。
- 浏览器使用独立的临时 Vite 服务和模拟登录响应，验证 role=0 登录跳转、新增、编辑、上下架、空表单校验；未使用真实商家接口或真实账号。
- 检查桌面 1366×960 和手机 390×844 布局。手机表格可以横向滚动，编辑表单单列显示。
- 独立代码审查发现的懒加载期间退出登录竞态已修复，新增回归测试通过。
