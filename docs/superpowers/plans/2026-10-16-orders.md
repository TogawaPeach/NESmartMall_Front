## 特别检查

- 账号切换及迟到请求不能保留旧地址或商品。
- ID 超过 JS 安全整数范围时保持字符串。
- 未付款 null 与已付 0 分分开；不允许金额汇总溢出。
- 页码/status 非法、重复查询参数和越界页不产生循环请求。
- 订单图片失败、长名称、长运单号在手机上不撑开布局。
