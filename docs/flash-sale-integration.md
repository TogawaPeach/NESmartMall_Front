## 当前行为

- 共享导航点击「限时秒杀」时先校验登录态；未登录弹出共享登录窗口并留在当前页，已登录进入 `/flash-sale`。直接访问专区而未登录时展示登录引导，不请求秒杀列表；登录态变化后重新加载。
- 专区容器、导航、正文与页脚的左右边界对齐主页：最大宽度 1440px，桌面水平内边距 80px、模块内缩 6px；1199px 及以下水平内边距 40px，599px 及以下为 20px、模块内缩 2px。
- 专区使用 Element Plus `ElCarousel` / `ElCarouselItem`，`type="card"`，突出中间商品并露出两侧卡片。每张卡片左侧为头图，右侧上方为名称、下方小字为型号，再展示价格和精简倒计时。整张当前卡片是详情链接，支持新标签页打开；没有立即购买按钮，没有下方商品网格。
- 秒杀详情为 `/flash-sale/products/:id`，路由 meta 决定使用秒杀详情 API。普通 `/products/:id` 继续使用原接口与交易流程。刷新、直达不依赖列表内存。
- 每件商品独立展示状态和倒计时，不按设备时间过滤列表。默认保留后端返回顺序，未开始、已结束商品也保留。活动状态计算统一为 `start <= now < end`，结束边界为不含。
- 默认每 4 秒切换；使用 Element Plus 自带前后按钮、指示器和卡片切换，支持左右方向键。悬停、键盘焦点在轮播内、页面隐藏、手动暂停时停止自动轮播。减少动态效果偏好下默认暂停。暂停按钮仅显示图标。单件时隐藏切换控件，空数组显示空列表。
- 页面只保留「限时秒杀」标题，已删除「经纬智选 / 限时好价」「每件仪器，独立开抢」「限时好价 / 精选仪器」等装饰文案。卡片只显示精简活动状态与倒计时，完整时间及购买校验提示保留在详情。
- 只有进入专区、手动重试或登录态变化时加载列表。切换卡片和计时不触发请求，不逐商品请求详情。
- 加载、空列表、失败、401 登录提示、403、404、接口未配置分别处理；封面缺失或加载失败显示占位。列表和详情请求使用 AbortController 与请求序号，页面/商品/来源/账号变化及卸载时取消旧请求并隔离旧响应。
- 秒杀详情不把商品传给普通购物车或普通购买逻辑，也不挂载普通下单小票；独立秒杀交易入口在 contract 中预留，当前显示「秒杀购买暂未开放」。

## 时间约定

用户已确认无时区时间统一表示北京时间。前端支持 `2026-10-22 16:00:53.581`、`2026-10-22T16:00:53.581` 及不带毫秒的对应格式，解析时明确使用 `+08:00`，不依赖设备时区。仍兼容带 `Z` 或明确 `±HH:mm` 偏移的时间并保留其实际时刻；允许 0～3 位毫秒精度。拒绝数值时间戳和无效日历时间；颠倒的区间仍判无效。缺少有效区间时显示「活动时间待确认」，仍展示商品。

显示时区固定配置为 `Asia/Shanghai`，页面标识北京时间。数据库 `DATETIME(3)` 本身没有时区语义，其北京时间含义来自上述业务约定。数据库工具中的格式不代表接口 JSON 一定相同，前端同时兼容无偏移及带偏移格式。

目前没有确认服务端当前时间字段，`time.clock = 'device'`，只供倒计时展示。若后端增加**每次响应生成**的权威当前时间，可切换为 `response-field` 并设置 `serverTimePath`，该值使用相同的 ISO 时间格式。不能使用缓存快照创建时间冒充当前时间。客户端时钟和网络耗时均可能造成展示偏差，前端不承诺服务端购买资格。每秒只更新本地时钟，页面重新可见时立即更新，不发送校验或刷新请求。
