## 1. 本轮完成范围

- 前端目录：`/Users/lightfull/NESmartChoice_Before/NESmartMall`。
- 共享 Axios 请求层统一处理认证，所有本项目后端 API（首页公开查询、分类、分页、搜索、登录）在会话 token 未过期时自动携带 `Authorization: Bearer <accessToken>`。

- 已检查所有现有业务 API 调用，登录与商品请求均使用共享 `http`；开发环境打开 README 的 fetch 不属于后端业务 API。
- 沿用现有登录弹窗，登录成功停留原页面；已登录时“查看全部”和首页搜索仍在新标签页打开。未登录时先引导登录，详见下文补充。

## 2. 跨标签页丢失登录的原因与修复

旧实现将会话写入 sessionStorage；新标签页通过 noopener 打开，没有继承原标签的会话，因而既不显示登录，也无法给后续 API 添加 token。

现改为同源 localStorage 共享，主键仍为 `nesmartmall.auth`，仅保存 accessToken、tokenType、expiresAt 和用户展示字段。按 expiresIn 计算 expiresAt，不硬编码 24 小时，不持久化密码。刷新、新标签页以及关闭浏览器后重新打开均可恢复未过期会话；过期或主动退出后清除。

`nesmartmall.auth.revision` 仅为共享状态的变更标记，不保存用户身份或刷新令牌：识别“匿名→其他标签登录→退出”即使最终会话又为空的情况，阻止迟到登录撤销退出；同时阻止已升级后从其他旧标签页再次迁移旧会话。

首次升级会迁移旧 sessionStorage 中的有效会话并删除旧记录；已有共享会话优先。应先刷新仍有有效旧会话的首页，再通过“查看全部”或搜索打开新标签页。

浏览器禁用存储或写入配额不足时仍允许页面内存登录；此时不能保证跨标签页共享或刷新恢复。读取与写入恢复后仍检查共享状态变化，不能永久停用同步，也不能用过期的旧持久化 token 缩短有效内存登录。

## 3. 会话清理与竞态约定

- 普通 API 的 HTTP 401 或业务 code=401，只在该请求发送的 token 与当前最新共享会话一致时清理。
- 登录失败的 401 只显示登录错误，保留原会话；HTTP 403、网络错误及 5xx 不清理会话。
- storage 事件同步同源标签页的登录、退出、过期及匹配 token 的 401 清理。
- 事件可能延迟，因此请求发送、401 处理及登录成功返回前重新检查共享状态，不直接回放事件中的旧值。
- 旧请求的 401、旧过期定时器、已退出或已被其他标签登录替代的迟到登录，不得删除或覆盖新会话。
- 写入后记录本次实际写入的快照，不把另一个标签抢先写入的会话误认为已被当前内存接纳。
- 退出只清前端共享会话，不调用尚未提供的后端注销接口，不表示服务端撤销 JWT；不增加 refresh token 或自动重试。

## 5. 后续工作与范围边界

本轮不需要后端读取浏览器 localStorage；后端无法直接读取浏览器存储，身份仍由前端 Authorization 头传递。

以下仍依赖后续后端或另一次前端任务，不能标为已实现：

- 网关对公开 POST /api/auth/login、GET /api/products 真正跳过验签，不能公开整个 /api/products/**。
- 网关验证受保护请求 token、清除外部伪造身份头并按验证结果转发可信用户身份。
- 业务服务恢复可信身份及检查内部调用来源、角色和资源归属。
- 订单、购物车的实际业务页面及入口、后台路由守卫、403 专用提示与商家导航。
- 服务端注销、刷新、即时撤销、账户禁用或角色变更后立即失效。

本轮未修改 Java、网关或数据库。前端新增匿名商品访问的登录引导，路由地址及已登录后的新标签页交互保持现有约定。后续接手先读取本文件、《用户入口与登录状态需求》和实际代码，再按用户授权继续。

## 6. 补充：未登录商品访问引导（2026-10-14）

- 首页及分类前八继续允许匿名加载。未登录点击任一“查看全部”时，留在当前页打开现有登录弹窗，并提示“登录后即可查看全部商品”；不再打开一个显示加载错误的新标签页。
- 非空搜索在未登录时提示“登录后即可搜索商品”；空搜索仍提示输入搜索词。已登录时查看全部与搜索继续在新标签页打开。
- 直接访问全部商品或搜索 URL 时，在原页面显示“请先登录账号”“立即登录”，不发送分页/搜索请求。点击按钮打开同一登录弹窗，保留当前分类、页码和搜索词。
- 在商品页登录后自动加载当前查询；退出、到期或当前会话的 401 清理后清空商品并恢复登录引导，取消旧请求并忽略迟到结果。不自动反复弹窗或重试。
- 网络错误、HTTP 403 和 5xx 继续显示商品加载失败与重试，并保留会话。登录接口失败仍在弹窗提示登录错误。
- 商品页登录成功时原“立即登录”按钮被结果替换，弹窗关闭后焦点回到持久的商品列表区域，避免键盘焦点丢失。
