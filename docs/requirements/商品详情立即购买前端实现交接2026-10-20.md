## 已确认范围

商品详情页点击“立即购买”，直接打开与购物车结算共用的纸质小票，仅包含当前商品 1 件。复用收货信息、创建订单、模拟支付及结果恢复逻辑，不先加入购物车，不新增后端接口或修改后端代码。

继续沿用现有 MQ 清理语义：创建订单全局提交后，按用户 ID 与商品 ID 删除购物车同款整行，不等待支付。购物车里没有该商品时删除 0 行，消费者不检查删除行数，因此不会仅因商品不存在而消费失败；若购物车已有多件同款，也会整行清理。用户已决定保持后端不变。本次未修改 MQ 配置、重试或异常处理。

## 前端实现

- `src/composables/useBuyNow.ts`：构造当前商品的单件小票数据；登录拦截；缺货或价格未提供时不可购买，允许 0 元商品；商品数据或账号变化时关闭小票。
- `src/views/ProductDetailView.vue`：将原“购买功能暂未开放”提示替换为结算小票入口；保留加入购物车原有行为；存在本次下单记录时提供查看状态入口。
- `src/components/storefront/CheckoutReceipt.vue`：购物车刷新回调改为可选，立即购买入口不额外查询或写入购物车；购物车入口继续传入原刷新回调。
- 继续复用账号范围内的 checkout store。关闭小票或切换商品不重置已创建订单/创建结果未知状态；再次打开不会直接重复创建订单，已知订单可通过原“开始新的购买”入口发起下一次购买。
